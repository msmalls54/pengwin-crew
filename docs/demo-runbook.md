# Pengwin live demo

Pengwin's four agents work in private `#pengwin-ops`. The [public judge lab](https://104-156-229-63.sslip.io) shows the separate, disposable execution environment required by Challenge 1. Give judges the `WEB_DEMO_TOKEN` from the ignored `.env` through a private channel; never put it in a public URL, video, or repository. That token can run code tasks and inspect their results, but cannot read office budgets or trigger office controls.

1. In Slack, mention Concierge or Buyer with **“Calculate 19 plus 23 and show the code you ran.”** The role listener should queue a run; the worker uses Vultr Serverless Inference to write Python and sends it to the sandbox VM. Show the reported result and code hash.
2. Open the judge lab, connect with the demo token, and enter **“Calculate 19 plus 23 and print the answer.”** Show the generated Python, stdout `42`, status, and code hash. The verified public run from September 26, 2026 is `526a55d6-811a-40ea-b5c4-9d1d7011cf5f`.
3. For the containment moment, enter **“Demonstrate sandbox containment by running an infinite loop in Python.”** Show the ten-second timeout and that a later ordinary calculation still works. The verified public run `676d9ebf-15e9-4763-9bb7-20343c5b5cf3` returned exit `124` and a visible timeout trace; a follow-up run returned `42`, and no ephemeral containers remained. Do not run a destructive command on either VM host. The container is read-only, has no network, runs as a non-root user with dropped capabilities and CPU/memory limits, and is removed after the run.
4. In Slack, ask Events for a free public RSVP page with an explicit future date, time zone, capacity, and HTTPS meeting link. Show the exact draft snapshot and `/crew review <run ID>`. For the demo, choose `/crew reject <run ID>` to prove no provider publication occurs without a matching admin approval. A real publish/readback has not yet been verified, so do not claim a public Eventbrite page was created during this walkthrough.

The recording should show the public URL, live model-generated code and execution output, the timeout, and the Slack approval boundary. A GitHub repository and this runbook are available; a recorded demo video still needs to be made and submitted.
